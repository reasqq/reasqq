- [Linux Helper](https://github.com/reasqq/linux-helper) — офлайн настольный учебник Linux и основ пентеста: 100 уроков, справочник инструментов, методология, безопасные сценарии и локальный прогресс. Electron, React, TypeScript; сборки Windows/Linux и CI.
- [Nmap XML Report](https://github.com/reasqq/nmap-xml-report) — офлайн Python CLI для разбора готовых XML-результатов Nmap и экспорта в JSON, CSV и Markdown. Не запускает сканирование и не объявляет версии сервисов уязвимостями.

- [Pentest Report Kit](https://github.com/reasqq/pentest-report-kit) — Python CLI для ведения карточек разрешённых учебных проверок и подготовки Markdown/JSON-отчётов. Находки и их серьёзность задаёт автор вручную.
- [CyberLab C++](https://github.com/reasqq/cyberlab-cpp-labs) — Windows-приложение с интерактивными лабораторными работами по C++17.
- [C++ Junior Trainer](https://github.com/reasqq/cpp-junior-trainer) — учебный тренажёр C++ с заданиями и проверкой решений.
- [Pocket Codex](https://github.com/reasqq/pocket-codex) — локальный мост к Codex App Server с очередью задач и подтверждением чувствительных действий.
